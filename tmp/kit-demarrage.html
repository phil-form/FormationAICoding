Conseils tirés de la session

  • Fais préparer le contexte (CLAUDE.md, specs dans tmp/) avant d'écrire du code : c'est ce qui rend les prompts suivants courts.
  • Pour un sujet structurant (secrets, authentification), demande d'abord une planification, fais écrire les phases dans Next.md, puis lance-les une par une.
  • Après chaque étape, fais un commit avec /commit : la suite de tests et les contrôles de sécurité tournent avant le commit.
  • Les points à trancher (Q1, Q2…) se règlent en dialogue (« réglons Q1 et Q2 ensemble ») et finissent dans un ADR.
  • En fin de journée, « exporte le context » pour reprendre la session suivante sans perte.
